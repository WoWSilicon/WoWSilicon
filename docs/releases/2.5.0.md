# WoWSilicon 2.5.0 is here. A new path.

We have a new name, a new launcher, and the project is once again open source.

## WoWSilicon

- You can now set up your own profiles for 1.12.1, 2.4.3, or 3.3.5a based clients.
- Allows the launch of third-party launchers.
- Installed addons are now renamed automatically.
- Addon lists can now be exported.
- Reworked the graphics settings section.
- Added a realmlist tab in the options.
- The launcher can now auto-update again.
- Added opt-in telemetry for stats tracking.
- Added a force quit button.

## CrossOver

- Ships with a custom `ntdll.so` which includes the Tahoe patch and `rosetta_x87_path` environment variable.
- Dropped CrossOver 25 support.

## New Game Patching Method

- All game versions are sharing the same patching method, which no longer modifies the game binary.
- Game validation will work properly again.
- Ascension can now be launched.

## libSiliconPatch for WrathSilicon

- Added 100 new function hooks which accelerate 3D performance.
- Overall, it delivers around 2x more FPS in crowded areas.

## d9vk

- Fixed a pipeline issue which caused cursor flickering.

## rosettax87_JIT

- Updated to the latest version.
- macOS 26.5 can be used.

Delete your old `TurtleSilicon.app` and replace it with this one.

As always, drag it into your Applications directory and run:

```sh
xattr -cr /Applications/WoWSilicon.app
```

Supported versions: macOS 15, macOS 26
