WoWSilicon now ships with its own Wine runtime. CrossOver is no longer required to install, configure, or play supported games.

## Standalone Wine Runtime

- Added a bundled Wine runtime, replacing the previous CrossOver dependency.
- Added Wine Mono installation to the Dependencies section.
- Added a confirmation prompt before deleting the shared Wine prefix.

## Graphics

- Added MTLd3D, a new graphics backend that translates Direct3D 9 directly to Metal, thanks to the work of [athei](https://github.com/athei/mtld3d).
- Added HDR support when using MTLd3D.
- D9VK remains available as the default graphics backend.

## x87 Translation

- Updated `rosettax87_jit` to the latest version, with performance improvements and support for macOS Golden Gate 27.
- Added [x87sidecar](https://github.com/athei/x87sidecar) as an additional x87 translation option alongside `rosettax87_jit`.

## Profiles and Launching

- Added experimental support for creating non-WoW profiles for 32-bit Direct3D 9 games.
- Users can now select any executable, improving support for clients that do not use the `WoW.exe` filename.

## User Interface and Process Management

- Improved interface elements to make controls more intuitive and folder paths easier to open and navigate.
- Added Wine process monitoring to the Force Quit control, making it easier to see when Wine processes are still running.

## Addon Manager

- Updated the addon manager to support nested addons, similar to GitAddonsManager.

As always, drag WoWSilicon into your Applications directory and run:

```sh
xattr -cr /Applications/WoWSilicon.app
```

Or use the updater within the app itself if you already have a previous version installed.

Supported versions: macOS 15, macOS 26, macOS 27
