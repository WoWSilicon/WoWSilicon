## Graphics

- Added KosmicKrisp as an experimental Vulkan driver option for DXVK 3.1. It requires macOS 26 or later
- Updated MTLd3D to 0.10.0 and Vanilla Tweaks to 1.6.0.

## Wine and x87 Translation

- Updated the bundled Wine runtime. Wine now keeps its user-profile directory inside the Wine prefix instead of creating a `Wine` directory in your home folder
- Updated x87sidecar to 1.7.0 and added its version to troubleshooting debug logs
- Added a prompt to install Rosetta 2 when it is missing

## Launching and Performance

- Moved game launch preparation off the main thread to keep the launcher responsive
- Reduced launch-time work by skipping unnecessary Wine audio startup, deferring Wine profile migration, and avoiding redundant dependency and option refreshes
- Reduced Wine process-monitoring overhead and replaced repeated window-focus polling
- Fixed relaunch after update behavior 
- Patching should be more reliable

## Profiles and Preferences

- Fixed settings from one profile reappearing in another, including cleared environment variables
- Restored the option to delete the WDB cache before launching
- Improved quoting of profile launch commands so paths and arguments with special characters work correctly

## Telemetry

- Added periodic, opt-in game-session heartbeats to improve active-user statistics

As always, drag WoWSilicon into your Applications directory and run:

```sh
xattr -cr /Applications/WoWSilicon.app
```

Or use the updater within the app itself if you already have a previous version installed.

Supported versions: macOS 14 (x87sidecar only), macOS 15, macOS 26, macOS 27
