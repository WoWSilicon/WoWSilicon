# WoWSilicon 2.5.3

## WoWSilicon

- Fixed a regression in 2.5.2 where patching could overwrite `Config.wtf` with a single line if the file used a non-UTF-8 encoding. This also caused repeated macOS prompts for access to removable volumes.

As always, drag it into your Applications directory and run:

```sh
xattr -cr /Applications/WoWSilicon.app
```

Supported versions: macOS 15, macOS 26
