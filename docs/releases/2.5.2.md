# WoWSilicon 2.5.2

## WoWSilicon

- Increased size of the Options popup
- Expanded support for custom launchers
- Fixed process stalling on read-only file systems
- Ensures `gxResolution` is present in `Config.wtf` when patching

## libSiliconPatch

- Disabled problematic particle hooks that could cause glitches and crashes on some clients
- Reduced binary size

As always, drag it into your Applications directory and run:

```sh
xattr -cr /Applications/WoWSilicon.app
```

Supported versions: macOS 15, macOS 26
