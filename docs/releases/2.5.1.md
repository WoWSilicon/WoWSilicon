# WoWSilicon 2.5.1 

## WoWSilicon

- Checks if game path is actually a client

## Dependencies

- Added a Dependencies tab in the options.
- Added one-click setup for the Microsoft Visual C++ 2022 runtime.
- The runtime is installed into the shared Wine prefix using the patched CrossOver binaries.
- Added Git detection for the addon manager.
- Added a Git install prompt when Git is missing and users open or use the addon manager.

## Addons

- Addon installs and updates now fail more clearly when Git is missing.
- Users can install Git from WoWSilicon instead of having addon actions silently fail.

## Telemetry

- Updated anonymous telemetry to support monthly public stats.

As always, drag it into your Applications directory and run:

```sh
xattr -cr /Applications/WoWSilicon.app
```

Supported versions: macOS 15, macOS 26
