## Wine

- Custom Wine bottle location! It is now placed in the home directory inside WoWSilicon and can be changed to any location
- Added a way to open the Wine terminal and Wine configuration for the WoWSilicon Wine runtime
- The open terminal action now uses a shell script to avoid hitting the maximum character limit with many environment variables
- Added a winemac patch to use the input source language in HKL, improving keyboard input for non-English layouts
- Added a winemac patch to ignore redundant screen parameter changes, reducing unnecessary overhead
- Improved Wine process management

## Performance

- Updated libSiliconPatch with 9 new hooks for Vanilla clients (+10% FPS)
- Updated libSiliconPatch for WotLK with 37 new hooks (+10% FPS)
- Updated x87sidecar to 1.6.0
- Fixed a lag spike caused by rapid clicking triggering excessive Window Server refreshes

## Audio

- New Audio tab! Added an Audio tab in Settings to select preferred output and input devices
- Automatic Audio switching! Audio output now automatically switches when the active device changes while the game is running. Bluetooth headphones like AirPods will switch without closing the game
- Added Apple Spatial Audio support for a more open soundscape.
- Added audio normalization to bring quiet sounds up and loud sounds down (for people with sensitive ears)

## Input

- Trackpads no longer have inertial scrolling and behave in a more controlled way
- Added GCMouse raw input support

## Profiles and Launching

- Added server management to the Realmlist tab for a nicer way to switch servers on the same profile
- Shortcuts support! You can now create a shortcut for a profile in a preferred state and launch directly without opening WoWSilicon

## Mod and Addon Manager

- Added third-party mod migration for (some) DLLs
- Added more guidance to the third-party launcher installation flow
- Fixed mod and addon manager directory buttons not opening

## Bug Fixes

- Fixed OptionAsAlt switch detection being broken
- Fixed the debug log failing to read a game directory
- Fixed an ancient bug that caused Vanilla and TBC clients to hang on exit

As always, drag WoWSilicon into your Applications directory and run:

```sh
xattr -cr /Applications/WoWSilicon.app
```

Or use the updater within the app itself if you already have a previous version installed.

Supported versions: macOS 15, macOS 26, macOS 27
